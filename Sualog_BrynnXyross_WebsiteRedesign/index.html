No login

Just pages. I keep them static on purpose so a traffic spike doesn't knock the server over.

Tables, not graphs

If you want a chart image, export the numbers and make one. I prefer seeing the actual values.

It stays up

Yesterday, last month, sometimes last year. That's kind of the whole point of keeping this around.
